# الهدف

توثيق جميع الأحداث (Domain Events) الرسمية في النظام.

كل حدث يمثل حقيقة تجارية (Business Fact) حدثت بالفعل.

لا يجوز إنشاء أحداث جديدة أو تغيير أسماء الأحداث إلا بتعديل هذه الوثيقة.

---

# المبادئ

- كل حدث حدث في الماضي.
- اسم الحدث بصيغة الماضي (Past Tense).
- الحدث غير قابل للتعديل (Immutable).
- كل حدث يملك ناشراً واحداً (Publisher).
- يمكن أن يملك عدة مستمعين (Subscribers).
- الأحداث لا تحتوي Business Logic.
- الأحداث لا تستدعي بعضها مباشرة.

# Integration Rules

- يمنع نشر Event باسم غير موجود في هذه الوثيقة.
- يمنع وجود أكثر من Publisher للحدث نفسه.
- يجوز وجود عدة Subscribers.
- لا يجوز حذف Event مستخدم دون تحديث جميع المستمعين.
- الأحداث تستخدم للتكامل بين Modules فقط.

---

# AI Agent Rules

قبل إنشاء أي Event جديد:

1. ابحث في هذه الوثيقة.
2. إذا كان الحدث موجوداً استخدمه.
3. إذا لم يكن موجوداً توقف واقترح تحديث الوثيقة.
4. لا تخترع أسماء جديدة.

---

# Definition of Done

أي Event يعتبر صحيحاً إذا:

✅ له اسم رسمي.

✅ له Publisher واحد.

✅ له Subscribers محددون.

✅ Payload معرف.

✅ Trigger معروف.

✅ لا يكرر حدثاً آخر.
