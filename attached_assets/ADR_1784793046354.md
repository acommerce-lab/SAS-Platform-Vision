# مقدمة

هذا الملف يمثل المرجع الرسمي لجميع القرارات المعمارية الخاصة بمنصة SAS.

أي قرار معماري جديد يجب أن يضاف إلى هذا الملف.

لا يجوز تعديل أي قرار أو تجاوزه داخل الكود دون تحديث هذا الملف أولاً.

جميع الوثائق الأخرى تعتمد عليه.

---

# ADR-001

## اسم القرار

Production First

## الحالة

Accepted

## القرار

المنصة تبنى للإنتاج منذ اليوم الأول.

لن يتم إنشاء نسخة Demo أو Prototype.

لن يتم استخدام أي حلول مؤقتة داخل الكود.

## السبب

المشروع سيستخدم مباشرة لدى العميل.

أي اختصار مؤقت يتحول لاحقاً إلى دين تقني.

## النتائج

يسمح

- Production Code
- Clean Code
- Tested Code

يمنع

- TODO
- Fake Services
- Mock APIs
- Placeholder Logic

---

# ADR-002

## اسم القرار

Single Company Platform

## الحالة

Accepted

## القرار

المنصة ليست SaaS.

اسم الشركة هو SAS.

النظام مخصص حالياً لشركة واحدة.

لا يتم دعم Multi-tenancy.

لكن يجب ألا تمنع المعمارية إمكانية إعادة استخدام النظام لاحقاً.

---

# ADR-003

## اسم القرار

Modular Backend

## الحالة

Accepted

## القرار

سيكون Backend عبارة عن مشروع واحد.

وليس عدة Microservices.

لكن يتم تقسيمه إلى Modules مستقلة.

مثال

Identity

Carrier

Driver

Truck

Shipment

Waybill

Notification

Support

Chat

لكل Module

- Controllers
- Services
- Repositories
- Validators
- Models

# ADR-004

## اسم القرار

API First

## الحالة

Accepted

## القرار

جميع العمليات تتم عبر REST API.

الواجهة لا تصل مباشرة إلى قاعدة البيانات.

كل عملية تمر عبر API.

---

# ADR-005

## اسم القرار

React Frontend

## الحالة

Accepted

## القرار

الواجهة تستخدم React.

لا يوجد Server Rendered UI.

لا يوجد Blade.

لا يوجد PHP Templates.

---

# ADR-006

## اسم القرار

Node Backend

## الحالة

Accepted

## القرار

الواجهة الخلفية تستخدم Node.js.

لغة المشروع JavaScript.

لا يستخدم TypeScript في الإصدار الأول إلا إذا تطلب الوكيل ذلك لتحقيق جودة أعلى.

---

# ADR-007

## اسم القرار

Workflow Engine

## الحالة

Accepted

## القرار

منطق انتقال حالة الشحنة يوجد في مكان واحد فقط.

لا يسمح بتكرار شروط انتقال الحالات داخل Controllers أو Frontend.

كل تغيير يمر عبر Workflow Service.

# ADR-016

## اسم القرار

Naming Convention

## الحالة

Accepted

## القرار

جميع الأسماء باللغة الإنجليزية.

لا تستخدم أسماء عربية داخل الكود.

تستخدم PascalCase للكلاسات.

camelCase للمتغيرات.

SCREAMING_SNAKE_CASE للثوابت.
